# 出差费用 APP 方案（公共钱袋 · 多币种 · 自动分摊）

> 阶段：方案稿（界面待方案确认后再做）

## 1. 核心概念

| 概念 | 说明 |
|---|---|
| **成员** | 出差人员，默认 5 人，可增减（如中途有人加入/离开） |
| **钱袋（公共资金池）** | 大家的钱放在一起统一花。钱袋下按币种分多个**币种账户**，如 CNY 账户、USD 账户、THB 账户 |
| **流水（每一笔记录）** | 所有进出钱袋的动作都是一条流水，有时间、地点、经手人、照片、备注，可点开查看详情 |
| **个人账** | 每个人"投入了多少"与"用掉了多少"，差额就是此人在钱袋里的余额 |

## 2. 流水类型（5 种）

1. **入袋（充值）**：某人往钱袋某币种账户存钱。记为此人"投入"。
2. **公共支出（分摊）**：从钱袋付款，给几个人一起用。
   - 输入**总金额** → 勾选参与人（默认全选 5 人，可取消，如只有 3 人吃饭）→ **自动平分**。
   - 也支持"按份数"（某人算 2 份）或"手动填各自金额"（总和必须等于总额才能保存）。
   - 平分除不尽时：分到最小单位（如 0.01），余数按顺序分给前几位，保证合计**一分不差**。
3. **个人支出**：从钱袋付款，但只算某一个人的（个人单独花）。
4. **换汇（结汇）**：从 A 币种账户换到 B 币种账户。记录"付出多少 A、得到多少 B"，实际汇率自动算出（含手续费也包含在内）。不算任何人的花费，只是钱袋内部转移。
5. **退款/调整**：退回钱袋，或纠错用；反向冲减对应人的花费。

> 可选扩展：**个人垫付**——钱袋没钱时某人自己掏钱付了公共开销，记为"此人投入 + 公共支出"两步，系统一键完成。

## 3. 自动分摊示例

晚餐 THB 1,000，参与 3 人（A、B、C）：
- 每人 333.33，余 0.01 → A 333.34，B 333.33，C 333.33
- 钱袋 THB 账户 −1,000；A/B/C 各自"已用"增加对应金额；D、E 不受影响。

## 4. 多币种处理

- 每个币种账户**独立记余额**，不会混算。支出用哪种币，就从哪个币种账户扣。
- 设一个**本位币**（如 CNY）用于汇总和最终结算。
- **折算规则（推荐：按实际换汇成本）**：
  - 钱袋里的外币是用本位币换来的，系统记住每个外币账户的**平均成本汇率**（加权平均）。
  - 外币支出折算本位币时，用该平均成本，这样大家分摊的是"真实花出去的人民币"，不受市场汇率波动影响。
  - 若某外币是直接现金入袋（没有换汇记录），入袋时需填一个汇率（可手填或参考当日汇率）。
- 个人账页面可同时显示：各币种明细 + 折合本位币合计。

## 5. 查看方式

- **总钱袋视图**：各币种余额、总投入、总支出、按类别/日期/地点统计；完整流水列表（可按时间、类型、币种、经手人、类别筛选和搜索）。
- **个人视图**：此人的投入、分摊到的每一笔（显示"总额 xx，你占 yy"）、个人支出、余额。
- **每笔可点开**：每条流水有唯一链接（如 `/tx/123`），在个人流水、总流水、统计里点击都能进入同一详情页。详情页显示：类型、金额、币种、折合本位币、参与人及各自金额、时间、地点、类别、经手人、备注、照片。
- **照片**：每笔可上传多张（小票、发票、现场照），列表显示缩略图，点击全屏查看、左右滑动、放大。上传前自动压缩，节省流量。

## 6. 结算

出差结束时：
- 每人余额 = 投入 − 已用（折本位币）。
- 余额为正 = 钱袋欠他；为负 = 他欠钱袋。
- 系统给出**最少转账方案**（例如"B 转给 A ¥230，E 转给 A ¥85"），剩余外币可选择按比例分给大家或换回本位币后再结。
- 可导出 Excel / PDF 报表（含照片链接），方便报销。

## 7. 登录与权限

- 一个"行程"（如"2026 曼谷出差"）对应一个钱袋，5 人都加入。
- 每人用自己账号登录，都能看全部账目（透明）。
- 角色：**管理员**（可改/删任何流水、管理成员）、**记账人**（可新增，可改自己录的）、**只读**。
- 所有修改、删除保留**操作记录**（谁、何时、改了什么），删除为"作废"可恢复，防止账目说不清。
- 支持一个人统一录入（替所有人登记），也支持各人自己录。

## 8. 技术方案（推荐）

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | Vue 3 + Vite，做成 **PWA** | 手机浏览器打开即可"添加到桌面"像 APP 一样用，iOS/Android 通用，不用上架应用商店 |
| 后端 | **PocketBase**（Go 单文件） | 自带账号登录、数据库（SQLite）、照片文件存储、实时同步、管理后台，开发快 |
| 部署 | Docker / docker-compose | 与本仓库现有方式一致，一台小服务器即可 |
| 离线 | 本地缓存 + 联网后自动同步 | 国外网络不稳时也能先记账 |

数据要点：
- 金额一律以"最小单位整数"存储（分、satang），避免小数误差。
- 汇率存为高精度小数，换汇记录保留原始两边金额。

主要数据表：`trips`（行程）、`members`（成员）、`accounts`（币种账户）、`transactions`（流水）、`splits`（每笔分到每人的金额）、`attachments`（照片）、`audit_logs`（操作记录）。

## 11. 需要你确认的问题

1. 本位币用什么？（默认 CNY）
2. 外币折算用"实际换汇平均成本"（推荐）还是"当天市场汇率"？
3. 是每人自己登录，还是只有你一个人记账、其他人只看？
4. 是否需要"个人垫付"（钱袋外自己掏钱）？
5. 部署：你有自己的服务器吗？还是先做纯手机本地版（不联网、数据只在一台手机上）？
6. 费用类别需要哪些？（建议：交通、住宿、餐饮、门票、通讯、杂费）
